# Log

## 2026-10-22

- TRIP-020: the start page in the design "Loungen". Every page has a header with the wordmark (`Wordmark`: the plane takes off into a brass ring once when the page loads, and hops on hover). The start page has the heading "Vi ordnar det ingen annan kan", a new text under it, an evening photo behind the top (`public/brand/skymning.jpg`, credited in the footer) and a smaller review carousel (15 × 12 rem). With reduced motion nothing moves. On a phone, Datum and Resenärer are side by side.
- TRIP-019: the admin page is built from the shared components in compact size: every text button is a `Button`, the cards are `Card`, dialogs float with the floating shadow (`floatClass`, also used by the suggestion list), the arrows that unfold a row are `IconButton`s, and "+ Lägg till klass/addon" is a quiet button. The stars in "Nytt omdöme" have a click area of 28 px (WCAG 2.5.8). `buttonClass` is removed, and `cardClass` and `compactCardClass` are no longer exported. The admin pieces are listed in `DESIGN.md`.
- TRIP-008: the foundation of the design "Loungen". Every colour, the font (Bricolage Grotesque instead of Geist), radii, shadows and motion are tokens in `app/globals.css`, and Tailwind's own palette is removed. Shared components (`Button`, `RoundButton`, `Field`, `Checkbox`, `Card`, `Message`) replace `ui.tsx`; fields show their label inside the box, with the placeholders "Varifrån?", "Vart vill du?" and "Välj datum"; messages are coloured text without a box. The admin page uses the tokens, its components follow in TRIP-019. Tests can check a page with axe (`expectNoA11yViolations`). Three of the design board's colours were made lighter to meet WCAG AA contrast. Described in `DESIGN.md`. The project moved out of OneDrive to `~/Documents/AI Projekt/gurrasflyg`, so the docs no longer say that OneDrive syncs `db/backups/`; nothing is copied to a cloud. The redesign was split into TRIP-008, TRIP-019 (admin), TRIP-020 (start page) and TRIP-021 (WCAG).

## 2026-10-21

- TRIP-007: the course's charter data (136 airports, 96 destinations with pages and photo credits, 500 timetables) is imported into tables of its own by two migrations, the data one generated by `scripts/generate-charter-data.mjs`; prices in whole kronor (EUR × 10). `GET /api/destinations` reads from the database. Found: two Antarctic destinations have no distance to their airport (a sea voyage), so that column may be empty.
- TECH-008: the backlog moved to the GitHub board "Gurras Flyg". A card holds what is built and why (the requirements); the repo holds how (`specs/<ID>-<name>/` with `solution.md`, flow, verification and review), in one flat folder per feature. The backlog table in `specs/overview.md` and the folders `backlog/`, `ongoing/` and `done/` are gone.
- TECH-007: "Preview tests" runs `npm test` against every pull request's preview deployment before merge; CI runs once per change (pull requests and `main`); the workflows share one setup (a Chromium cache was measured and removed: it saved nothing); the seats fields and add-on price read whole numbers with one shared `parseWholeNumber`.
- TECH-005: all prices are whole kronor instead of öre. Migration `004_whole_kronor.sql` converts the stored prices; an add-on price with öre gives "Ange priset i hela kronor.", and the price field is a text field, since a number field turned "12,50" into 1 250 kr.
- TECH-006: code review as a step in the workflow. A reviewer agent (`.claude/agents/code-reviewer.md`) follows the guide in `wiki/system/code-review.md`; its report is saved as `review.md` per feature and posted on the pull request.
- TECH-002: removed leftovers (the project template's images in `public/`, `getAirports` and `textareaClass`); the review text limit is defined once, in `lib/review-rules.ts`. No change for visitors.

## 2026-10-20

- TECH-001: GitHub Actions pipeline. CI checks every push and pull request; Live tests run against the live site after every production deploy.
- Fixed in the reviews carousel (TRIP-006): a swipe also counted as a click on the card it ended on, so the cards stood still. Found by the first CI run on GitHub.

- Added the course sample data (`data/`, `knowledge/`, `public/images/`) and `GET /api/destinations`.
- Moved the local database out of OneDrive to `~/Ai Projekt/gurrasflyg-data/gurrasflyg.db`. Backups are saved in the project's `db/backups/`, synced by OneDrive, every time `npm run dev` starts and with `npm run db:backup`.
- Specified the features built before this date, TRIP-001 to TRIP-006, in `specs/`, with Playwright tests per requirement and verification records. All tests pass locally and against the live site.
- `npm run test:local` now runs a production build against its own fresh test database (`~/Ai Projekt/gurrasflyg-data/test.db`); leftover "E2E" test data is removed after every run.
- User manual (Swedish): searching for flights, reviews, and the admin pages. System documentation: `GET /api/airports`.
